# Décisions de l'utilisateur sur la doctrine et les ordres (19/10/2026)

1. Le pourcentage « 55 / 45 » n'est pas une prédiction : à statistiques égales et à tactique égale, sur des centaines de batailles. Dans une vraie partie, la tactique du joueur reste la clé ; une équipe à 60 % peut perdre si le joueur joue mal. L'entente ne touche que le travail d'équipe, jamais le tir.
2. Dans une escouade mélangée, c'est la minorité qui paie.
3. Pour réduire la pénalité : le chef (trait Meneur) seulement, pour commencer.
4. Une seule doctrine pour l'instant : GIGN.
5. Porteur de bouclier : plus tard.
6. Clic droit n'importe où sur la carte ; le joueur décide (qui reçoit l'ordre, où, comment).
7. Bulles de texte : oui. Pas de voix.
8. Prochain pays : Royaume-Uni.
9. L'entente se fera quand il y aura des opérateurs d'un autre pays.
10. L'ennemi (sans pays) : entente au maximum (souvent le même groupe).
11. Si un opérateur tombe, on garde l'entente du départ.

- Les derniers choix sont présélectionnés. Clic droit + glisser déplace toujours la caméra.
